# HKO Weather Icons

A collection of weather icon images sourced from the [Hong Kong Observatory (HKO)](https://www.hko.gov.hk/), converted to **single-color (black)** for optimal display on **e-ink screens**.

## 🖥️ E-Ink Display

All icons have been converted to **single-color black** to ensure crisp, high-contrast rendering on e-ink screens. The transparent background makes them easy to composite over any light-colored surface.

## 🚀 Usage

This repository is intended for **non-commercial use only**.

You can reference any icon directly via its raw GitHub URL:

```
https://raw.githubusercontent.com/cyrus-tsoi/hko-weather-icons/main/pic<code>.png
```

**Example** — display the "Sunny" icon:

```html
<img src="https://raw.githubusercontent.com/cyrus-tsoi/hko-weather-icons/main/pic50.png" alt="Sunny" />
```

Or in Markdown:

```markdown
![Sunny](https://raw.githubusercontent.com/cyrus-tsoi/hko-weather-icons/main/pic50.png)
```
